# DJUPPE — implementation plan

## Visual system

- Build a furnace-black editorial canvas with steel, graphite, temper-blue, violet, amber, and welding-white accents.
- Use monumental condensed display typography, a restrained grotesk for reading, and a mono face for fabrication data.
- Treat rules, coordinates, stamps, registration marks, seams, and material gradients as structural elements—not decoration.
- Give motion weight: slow reveals, masked sheet-like transitions, restrained pointer response, and reduced-motion equivalents.

## Build sequence

1. Establish Next.js, TypeScript, Tailwind, fonts, metadata, content data, and global tokens.
2. Build the persistent navigation, reusable procedural media, section labels, and motion primitives.
3. Build the WebGL forged-ribbon hero with manufacturing details, responsive controls, reduced-motion handling, and a static fallback.
4. Compose the seven homepage chapters with deliberately varied editorial layouts.
5. Build typed, statically generated project detail routes and replacement-ready image handling.
6. Add robots, sitemap, structured data, generated icon, and Open Graph artwork.
7. Run lint, type checking, tests, production build, route checks, and responsive visual inspection; fix all material issues.
